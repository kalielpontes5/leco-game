# LECO: ALEM DO VERDE

Jogo de investigacao ambiental em pixel art.

## Estrutura

- index.html: estrutura principal.
- css/styles.css: identidade visual e estilos.
- js/game.js: logica original completa do jogo.
- assets/: recursos externos futuros.
- backup/: copia integral do HTML original.

## Preservacao

O codigo original foi separado sem refatoracao da logica.
Nao modificar mecanicas, personagens, fases ou identidade visual
sem solicitacao expressa.
